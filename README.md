STEM Connect

About:
STEM Connect is a web application that helps students organize their academic and practical lives by providing many features that can help with studying, such as
a study planner, a to-do list, flashcards, and more. It also provides opportunities that can help them strengthen their CVs. In addition, the platform provides 
students with a fun vibe by offering many games, fun facts, and more, all in one page called the Fun Zone.

Features:
-Study Planner
-To-Do-List
-flashcards
-Opportunities
-Fun Zone
-Career Campass
-Responsive Design
